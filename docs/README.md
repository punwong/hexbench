## 截图

`assets/` 里是开发过程中验证用的截图，**README 不引用任何图片**。
命名按主题前缀：

- `launcher-*` —— 快捷面板
- `settings-*` —— 设置页
- `phrases-*` / `panel-*` —— 常用语面板
- `ui-*` / `update-*` —— 主界面与更新提示
- `web-*` —— 网页窗口
- 其余（`context-menu`、`trigger-blue` 等）按内容命名

同一个界面往往有多张截图（不同迭代版本），**以最新的为准**；
发现重复或过期可以直接删。
