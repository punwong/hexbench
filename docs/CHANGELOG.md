# 变更记录

只记「用户能感觉到」的变化。内部重构、日志调整不列。

## 未发布

**呼出面板 · 拖放**

- 修复：**把文件拖进「快速访问」里的另一个文件夹后，面板还显示那个文件夹是空的**
  （文件其实已经移进去了）。这类文件夹的列表有一份给拖拽预览用的缓存，
  移动 / 粘贴之后没有作废，界面重绘时又把旧列表画了回去。现在目录内容一变，
  这类缓存就作废、重新读一遍。

## 0.6.1

**呼出面板 · 视图**

- 新增**「使用频率」排序**：按在面板里打开过的次数排，常打开的排在最前面；次数相同的
  仍是文件夹在前、按名称排。次数只记在本机（配置目录的 `usage.json`），不进配置同步。
- **快速启动（分类）和快速访问（钉住的文件夹）的视图 / 排序分开记**：一边用图标、
  另一边用列表互不影响，重开面板也各是各的。快速访问还没单独设过时先跟着分类走，
  第一次在里面改过之后就独立了。

**呼出面板 · 动效**

- 侧边栏的选中高亮改成**一块会滑动的滑块**：切换分类时从上一行滑到下一行
  （240ms 弹性曲线），不再是一行变色、另一行掉色。
- 换分类、换排序、切列表/网格时，新内容 200ms 淡入并轻轻上移一点。
- 每次呼出面板都播一次 140ms 淡入。之前这条动画只在页面第一次加载时跑，
  第一回之后再按热键，面板是「啪」地出现的。
- 缩略图解码完成后 140ms 淡入，不再同时跳出来；滚回去看过的图直接出成品，不重播。
- 格子、列表行和各个小按钮统一 120–130ms 的悬停 / 按下反馈（按下轻微缩小）。
- 系统里关掉动画（减少动态效果）时，以上动效全部不播。

**呼出面板 · 缩略图**

- 修复：大目录（上千个文件）里缩略图「加载得很慢」。原因是一批 64 张要**等整批**
  才一起显示，一批里最慢的那张（大视频、网络盘）会把已经抽好的全扣住。现在
  **抽好一张显示一张**；后台固定 6 个线程并行抽取，屏幕外再预取一屏多，
  滚动时已经准备好（可见的那一屏永远排在预取前面）。
- 修复：非方形的缩略图被拉成了 1:1（照片、视频首帧看起来变形）。现在保持原图比例，
  和资源管理器一致。
- 修复：Shell 偶发失败一次，这个文件就一直是通用图标。现在会立刻重试一次；
  切目录 / 刷新时也会重新问，一次卡顿不再变成永久回退。
- 修复：**拖着文件悬停到侧边栏的分类 / 常用文件夹上，预览出来的那一屏缩略图是空白的**。
  拖拽那一下系统把界面线程占住（松手才还回来），这期间新的缩略图请求一律排队，
  所以预览只能是空白。现在面板闲着时就把侧边栏每个文件夹头一屏的图标先备好，
  拖着过去直接出图。

**呼出面板 · 拖放**

- 新增：**拖到上方的面包屑上松手，就能把文件移进那一层目录**。进了子文件夹以后
  想把文件挪回上一层，不用先退出去再重拖；拖着经过时目标那一段会亮一圈。
- 修复：**把文件拖到另一个分类 / 常用文件夹里，松手后会弹一句「文件已经不在了」**。
  文件其实已经移过去了，只是同一个动作被处理了两遍——第二遍找不到源文件就报错。
  现在一次拖放只认一次，不再误报。

## 0.6.0

**命名**

- 「快捷启动」改叫 **快捷面板**：它现在是个按分类找文件、搬运文件的面板，不只是启动程序。
  设置里的三个标签跟着改：**快捷启动**（分类根目录与顺序）、**快速访问**（钉住的文件夹）、
  **内置网页**（网址）。

**呼出面板 · 分类与搜索**

- 修复：同一个文件夹既在「快捷启动」又在「快速访问」时，侧边栏的高亮会亮错行
  （尤其是拖着文件往另一行悬停的时候，两行共用一个键，换不过去）。
  现在两行各自独立；重新呼出面板也会回到上次停的那一行。
- 搜索改成**跨所有分类**：在任意分类下输入关键词，找的是全部分类的文件，
  底栏跟着写明「所有分类」。

**呼出面板 · 文件区性能**

- 网格 / 列表改成**虚拟滚动**：只渲染屏幕上能看到的几十项，几千项的目录也能滚得动。
- 目录改成**流式加载**：先出前几百项，剩下的边读边补；面板自身不再有 1000 项上限
  （一次性接口的上限提到 20000，只用于预读）。
- 图标**按可见范围按需取**，并通过 `hbicon://` 协议直接从磁盘给 WebView
  （不再把 base64 塞进 IPC）。
- 取图标改成**多线程并行**（每线程自己的 COM 公寓和图标列表）。
- 缩略图先查**系统缩略图缓存**（和资源管理器共用），没命中再抽取。
- 修复：取不到图标时不再落盘成“永久没有”——Shell 偶发失败一次，之前那个文件
  就再也不会出图了。
- 隐藏 / 系统属性文件不再列出来（和资源管理器默认视图一致）。
- 复制 / 移动撞名时自动编号成「xxx - 副本」，不再弹替换询问。
- 改名改走 `IFileOperation`，只改大小写现在也能成功。
- 去掉搜索框旁边的「新建文件夹」按钮（空白处右键就能建）。
- 修复：设置里关掉「内置网页」后真的一个 WebView 都不建了（之前 `web.html`
  照样加载，还会自己打开第一个站点）。
- 修复：拖拽被系统取消（拖到面板外松手）时，面板会一直停在旧目录不再刷新；
  现在超过 1.5 秒没有新的拖拽坐标就当作拖拽结束。

**窗口**

- 修复：**快捷面板四个角的圆角不对**。面板是不占任务栏的工具窗口，系统不会给它剪圆角，
  之前是靠页面自己画一圈——圆角外面那圈三角露出的是网页底色：深色主题下四个角是四个白点，
  浅色主题下描边又被系统剪掉一截，和设置窗口的圆角对不上。现在直接让系统按同样的 8px 剪。
- 修复：**连续呼出呼入几次后面板卡死、快捷键没反应**。原来呼出后«抢前台»那步在
  后台线程上跨线程 `SetFocus`，主线程正走在键盘消息里时两边互相等，整个界面就僵住；
  现在这步排回窗口自己的线程执行。
- 从右键菜单里选**压缩 / 复制 / 发送到**这类系统命令后，面板不再立刻被收起：
  命令还在跑（目标目录还在变）就一直留着，跑完了再按原来的规则收。
  用的是资源管理器 / 7-Zip 的原生菜单项，没有另外做一套压缩。

## 0.5.0

**文件管理（本次重点）**

- 文件区**空白处右键**弹出资源管理器的原生背景菜单：新建、属性、刷新，
  以及已安装的扩展（Git、VS Code、7-Zip……）。手写 Shell COM：
  `IShellFolder::BindToObject` + `CreateViewObject(IID_IContextMenu)`。
- 该菜单里补了「粘贴」（标准项在 Shell 视图层，文件夹菜单拿不到）。
- **删除到回收站**：`Delete` 键，走 `IFileOperation`，系统弹确认。
- **Ctrl+Z 撤销**：删除（从回收站还原）、重命名、移动、新建文件夹，最多 30 步。
- **Ctrl+C / X / V**：写系统剪贴板 `CF_HDROP` + `Preferred DropEffect`，
  和资源管理器互通（这边复制、那边粘贴也行）。
- 原生菜单里新建的条目会自动出现在面板里（之前要重新呼出）。

**窗口**

- 网页窗口可**拖顶栏移动**、**拖边角改大小**，位置和大小会记住。
- 新增设置「记住网页窗口的位置和大小」（默认开）。
- 呼出面板也可**拖边角改大小**，尺寸会记住（设置里可关）。
- 修复：面板缩放后网页内容半边空白（子 WebView 没重排）。
- 修复：网页窗口位置记不住（拖动事件被节流丢掉；隐藏时存下临时坐标）。
- 修复：无边框窗口拖不动、拖不大（顶栏加拖动区、四周加热区调 `startResizeDragging`）。

**外观**

- 面板和网页窗口**跟随设置里的主题**，切换立即生效（之前只认系统主题）。
- 网址设置页改用与其他页一致的 `Slider` / `Segmented`。
- 侧边栏：同一个文件夹既是分类又是常用文件夹时，不再两个一起亮。
- 侧边栏：去掉 WebView2 的原生提示框（跟着鼠标走的黑边方块）。
- 侧边栏：悬停高亮更跟手（高亮立即响应，内容切换 25ms）。
