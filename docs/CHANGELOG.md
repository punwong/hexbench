# 变更记录

只记「用户能感觉到」的变化。内部重构、日志调整不列。

## 0.12.1

**修复**

- 修复快捷面板多选文件后，右键菜单里的删除只删掉一个的问题：菜单现在作用于整组选中项，
  剪切、复制、发送到等系统命令同样如此。
- 多选后单击其中一项，松手时收窄为只选这一项（之前会保留整组，接着按 Delete 会多删）。
- 搜索结果里跨文件夹多选后右键，菜单和选中项现在收窄到点中的那个文件夹，不会再出现
  「选了 3 个、只删掉 1 个」。
- 输入搜索词后，选中项只保留在结果里还看得见的那些：Delete、Ctrl+C 不会再带上
  被搜索过滤掉、屏幕上没有显示的文件。
- 批量操作（删除、复制、剪切、粘贴）里混着已经不存在（被别处删掉或移走）的路径时，
  跳过失效的那些、其余照常执行，不再整批失败。
- 桌面格子点搜索后，搜索框左边不再漏出半个文件夹图标：输入框从图标右侧展开，
  完整盖住标题，子目录里也不会压住返回箭头。
- 快捷面板和桌面格子的右键菜单里，「打开方式」的子菜单现在直接列出常用程序
  （记事本、VS Code 等），点一次就能选；以前只会出现「选择其他应用」，还要再点一次。
- 空白处右键的「新建」子菜单现在真的能建东西了（文件夹、文本文档），建好直接进入改名；
  以前点了一点反应也没有。

## 0.12.0

**边缘桌面**

- 移除「测试模式」：该开关只用于开发调试，对日常使用没有意义；「在屏幕上预览」仍会把
  触发带画在屏幕上 5 秒，用来确认位置或排查误触，不会切换桌面。

**边缘桌面 · 多屏**

- 修复：两块屏幕左右拼接、其中一块更矮时，接缝露出来的那一段被当成了「可触发边缘」——
  设置里的预览会在接缝处画蓝色，鼠标推过去也会真的触发。接缝不是桌面的外沿（光标跨不过去），
  现在整条边都不再触发，预览里也只保留整块桌面最左 / 最右的边。

**关于**

- 去掉「更新源」输入框：更新源固定用内置地址，不再让用户填镜像。需要自建镜像 / 内网分发的，
  直接改源码（MIT 开源），不占设置页的地方。

**快捷面板**

- 统一空态与页脚的说明文字：没有匹配结果、没有便签、读取中等状态各自说明当前情况；
  文件页脚只保留常用操作提示。
- 便签读取失败时给出「重试」和「关闭便签」，不再只显示一行错误文字。
- 搜索时底部范围统一显示为「全部」。

**托盘与更新**

- 托盘菜单的「暂停边缘切换」改为带勾选状态，与设置里的暂停开关保持一致。
- 自动更新改为每 10 分钟检查一次；侧边栏的更新入口缩为图标加「更新」。
- 修正更新状态提示：下载完成后提示点「更新并重启」安装，检查或安装失败时给出重试提示。

**设置**

- 精简各设置页的说明文字：删掉重复解释控件用途的整段描述（更新、热键、快捷面板、桌面格子、
  手势等），只保留操作提示和会产生后果的提醒；「关于」页去掉版本、定位等与更新卡重复的信息。
- 调整设置页的排列：「通用」按开机自启、主题、显示器、存储、同步、配置文件排；快捷面板把呼出位置
  和面板尺寸放在分类列表之前；桌面格子先列格子再调外观；触发带按「边 → 侧 → 比例」排。
- 导航分成「工具」「应用」两组；工具关掉后入口和「设置」按钮也一直留着，不用先打开才能改设置。
- 快捷面板的页签改叫「分类」「固定文件夹」；边缘桌面的第一张卡改叫「预览」，按钮改为
  「在屏幕上预览」，「启用边缘」改为「左右两侧」。
- 停留阈值、冷却、内推距离、轮询间隔改成直接输数字；轮询间隔收进「高级」。
- 「通用」里的「启动」和「外观」合成「常规」；原来的「缓存」页并进「通用 → 存储」。
- 清空全部便签、删除格子改用统一的确认框，危险按钮标红，不再用系统 confirm。
- 「关于」页加上应用图标和 GitHub / 问题反馈 / 更新日志 / 许可证链接；诊断信息收进「反馈」里的
  折叠区。更新卡显示上次检查时间和「已是最新版本」，有新版本时列出更新内容；
  设置窗口在任务栏里显示为「HexBench 设置」。

**修复**

- 修复：设置窗口被其他窗口遮挡一段时间后再点回来会变成「未响应」。原因是 WebView2 的
  原生遮挡计算会冻结渲染进程，现在所有窗口都关闭了该特性。

## 0.11.0

**收藏 · 钉在桌面上的便签**

- 收藏里的每条笔记多一个**钉子**按钮：点一下，这条笔记就在桌面上开一个小窗，正文按
  Markdown 排版、图片直接显示。窗子**始终置顶**、不进任务栏，拖到哪儿、拉多大都是
  下次启动原样回来；再点一次钉子，或者点窗口右上角的「取消钉住」就收起来。
- 便签窗可以**收起**成一条标题栏（和桌面格子一样）：双击标题栏，或者点右上角的箭头。
  收起状态也记进配置，下次启动还是收着的；收起时还能拖位置，展开后回到原来的高度。
- 便签窗里双击正文（或点铅笔）就地改，**完全自动保存**（停下 450 ms 就写盘），
  只留撤销 / 重做（Ctrl+Z / Ctrl+Y），没有保存按钮；外面改了同一条笔记，没在输入时也会跟着刷新。
- 删掉笔记、清空收藏、按 Alt+F4 关窗都会同步取消钉住，配置里不会留下打不开的窗；
  暂停查看时把窗关掉即可，下次从收藏里的钉子重新打开。

**呼出面板 · 笔记自动保存**

- 面板里的笔记编辑器改成**完全自动保存**：去掉「保存 / 取消」和 Ctrl+S，只留撤销 / 重做；
  Esc 或点面板外关掉时，没写完的内容也会先存好。


## 0.10.1

**界面**

- 界面图标统一成 **lucide** 一套：设置页本来就用它，呼出面板的排序 / 视图 / 搜索
  换成同一套，桌面格子的原生渲染也按同一份图标数据（`scripts/gen-icons.mjs` 生成）
  绘制——三处的形状、线宽和圆角一致。文件类型图标仍用系统的。
- 呼出面板的列表视图补上**列名**（名称 / 修改时间 / 大小），点列名按这一列排序、
  再点一次反向，和桌面格子的列表一致；行里的「修改时间 / 大小」也换成同样的顺序。
- 工具条 / 标题条上的图标统一成 **16px**（桌面格子的搜索、视图、更多，呼出面板的
  排序、视图、搜索，设置里格子那一排按钮）；前进 / 后退箭头保持 18px。
- 桌面格子的**搜索框**换成呼出面板那种样子：24 改成 26px 高、圆角、浅灰填充
  （深色主题同色系），左右留白也更宽。

**性能**

- 设置窗口关闭后**5 秒**回收它的 WebView（原来要等 30 秒），空闲内存更快降下来，
  大约少占 40–50 MB；呼出面板的 WebView 仍然常驻，唤出速度不变。

## 0.10.0

**桌面格子**

- 格子只保留**原生渲染**：每个格子不再是一个 WebView，设置页里那个「原生渲染（Beta）」
  开关也去掉了。内存和启动都比原来小，行为和外观不变。
- 新增**锁定位置**：标题条「⋯」菜单和设置页都能锁 / 解锁。锁定后拖不动标题条、
  拉不了边角，双击卷起、面包屑和菜单照常。
- 新增**列表视图**：标题条右侧（原来显示文件数的地方）多了一个切换图标，点一下就在
  **图标网格**和**一行一个**之间切换；设置页里也有同样的按钮，每个格子各自记住。
  行高 28px、图标 18px，名字太长末尾省略。
- 新增**多选与批量操作**：按住 Ctrl 点选、Shift 连选，或者在空白处拖出框选；
  选中之后可以整组拖到别的程序 / 文件夹，右键菜单里的复制、剪切、删除也一次作用到
  所有选中项（多选时菜单不带「重命名」）。点一下已选中的那一项就收窄成只选它。
- 新增**格子内搜索**：标题条右侧多了一个放大镜，点开就地输入，边打边按名字过滤；
  回车保留筛选、Esc 清空，放大镜变成正文色表示这一格正在过滤。
- **列表视图**多了「修改时间 / 大小」两列（文件夹的大小留空、今年只写到分钟），
  顶部的列名点一下按那一列排序、再点一次反向；「⋯」菜单里也补了**按大小 / 按类型排序**。
- 标题条的放大镜、视图按钮和列表列名悬停时有浅色反馈和手型光标。
- 托盘菜单新增**「显示全部格子」**：把隐藏掉的格子一次放回来。
- 修复：鼠标扫过格子里的文件时，标题条前面的**文件夹小图标会一闪一闪**。

**呼出面板**

- 修复：把文件删进回收站之后**紧接着按 Ctrl+Z 没反应**。系统处理回收站时会把键盘
  焦点从网页收回窗口本身，之后窗口虽然还在前台，按键却进不到页面；现在删除 / 撤销
  结束后自动把焦点交还网页，不用再点一下面板。
- 修复：在面板里拖图片时，**正在编辑的新笔记**接不住图——拖到正文里不插入、拖出去
  也不新建，现在都会正常导入。
- 修复：新建的空笔记保存失败后再点保存会**多建一条**，现在接着写原来那条。

**设置**

- 修复：连着改几项设置时，后一次保存可能把前一次刚同步过去的设置**盖回旧值**
  （比如内置网页的开关）。
- 修复：热键录制框点到别的窗口后仍停在「按下新的组合键」。
- 修复：正在编辑格子的「自动整理规则」时，保存别的设置会把**敲到一半的规则换回旧内容**。
- 修复：浅色主题下有些分隔线看不见；设置页里过长的热键名会把整行撑破，现在末尾省略。
- 新增：内置网页可以选**跟着呼出面板走**，以及**记住位置和大小**（关掉则每次按设置的
  宽度 / 高度重新摆）。

## 0.9.0

**桌面格子**

- 新增**桌面格子**：在桌面上摆几个绑定文件夹的小组件，文件拖进去就算整理好；
  系统桌面图标照常使用，不接管、不隐藏。
- 格子贴在桌面图标层之上、普通窗口之下，点它不抢焦点、不进 Alt+Tab；按 Win+D
  默认保持可见（设置里可以改成跟随桌面隐藏），Explorer 重启后自动重新落位。
- 卡片是**磨砂亚克力**：Win11 22H2+ 走系统背景材质，Win10 走 Acrylic，都不行就退回
  纯色卡片；背后的壁纸模糊着透出来，缩放 / 卷起时不会闪黑。
- 设置里新增**「外观」**：**不透明度**（30%–100%）和**磨砂开关**，所有格子共用，
  拖滑块时格子当场跟着变。关掉磨砂就是纯透明玻璃——壁纸原样透出来，不模糊。
  格子里的滚动条也跟着不透明度一起变淡，是一条细线，没有灰色底槽。
  标题条「⋯」菜单始终是不透明的浅色板，不跟着卡片变透，免得底下的文件透上来糊成一团。
- 修复：格子有时会**浮在所有窗口上面**，像一块置顶面板。按 Win+D / 显示桌面时桌面会被
  抬起来，那一刻重新锚定会顺手把格子标成置顶；另外应用启动时有程序正最小化着，格子也会
  被插到它上面。现在格子只插在桌面层正上方，永远被普通窗口盖住。
- 修复：把格子拖到屏幕边缘松手时**会往回跳一下**（拖动时能跑出工作区，松手才被夹回来）。
  现在拖到边上就顶住，松手不再跳。
- 修复：从桌面（或资源管理器）**拖文件进收纳盒时整个拖拽卡死**。拖放目标原来是在建窗的
  后台线程上登记的，而 OLE 只把拖拽回调交给「登记它的那条线程」、那条线程又从不处理消息——
  资源管理器一拖进来就永远等在那里。现在格子和呼出面板的拖放目标都登记在主线程上，
  拖进空白处 / 子文件夹、撞名自动编号都正常，也不会再拖住别的程序。
- 拖动标题条移动、拖边缘或四角缩放，靠边 / 靠其他格子时吸附并显示参考线，
  按住 Alt 可临时暂停；双击标题条卷起，卷起后只能改宽。
- 吸附参考线改成**横跨整屏的虚线**：不再只画在格子自己身上，而是从正在拖的格子一路画到
  被对齐的那一格（左边对左边、顶边对底边…），可以越过别的窗口、也能跨到副屏。
  线由一层覆盖整个虚拟屏幕的透明置顶画布画，点击穿透、不进任务栏；拖动时出现，松手即消失。
- **深色模式统一**：桌面格子、呼出面板、网页窗口原来只认系统深浅，设置里切
  浅色 / 深色不会传过去；现在它们和设置窗口用同一套主题，改完当场变色（选「跟随系统」时
  系统换主题也跟着换）。滚动条、输入框这类系统画的东西也按深浅走，深色下不再留白条。
- 位置和尺寸按显示器工作区归一化保存：换分辨率、改缩放、拔掉副屏都会按比例落回；
  每个格子的排版缩放（Alt+滚轮，100%–150%）也各自记住。
- 格子里可以双击进入子文件夹、返回上一级；右键是系统原生文件菜单（新建 / 粘贴 /
  重命名 / 删除）；文件可以从格子里拖到资源管理器，也可以从外面拖进来。
  停在绑定文件夹本身时标题条不再显示返回箭头，进去子文件夹才出现，也就没有「点了没反应」
  的灰按钮；Backspace / Alt+↑ 在根目录同样不动作。
- 进了子文件夹后标题条变成**面包屑**：`界面测试 › 子目录`，每一段都能点回那一层，
  和快捷面板的文件区一致；最后一段用正文色标出当前位置。从外面把文件拖到某一段上松手，
  就落在那一层（悬停高亮同文件区）。停在绑定文件夹本身时仍是格子名字。
- 设置里新增**「桌面格子」页**：总开关、Win+D 行为、吸附与网格、添加 / 显示 / 删除格子；
  收纳盒的整理规则（来源、条件、子目录、自动整理）也在这里编。侧栏里它挪进了**「工具」**，
  概览页也多了一行开关：和快捷面板 / 边缘桌面一样一眼就能开、能关；关掉后格子窗口
  收起、这一页跟着隐藏，再打开位置尺寸原样回来。
- 文件区也支持**右键手势**：按住右键左右划，默认左划返回上一层、右划回到刚才退出的那一层，
  走的是你在格子里进出过的目录（最多记 50 层，换绑文件夹就清空）。手势的开关 / 方向 /
  触发距离 / 轨迹和快捷面板**共用**一份设置，在设置页改完所有格子当场生效。
  右键慢慢点开菜单不受影响，只在真正横着划出一段之后才拦掉右键菜单。
  设置页里的「手势」也从**「工具」**挪到了**「全局」**（和「热键」放一起）：这份设置两个工具
  共用，不再像是某一个工具的专属项；两个工具都关掉时它照旧隐藏。
- 新增**桌面右键菜单**（默认就有）：右键桌面空白处 → **HexBench** → 新建格子…（选一个文件夹）/
  新建收纳盒 / 显示 / 隐藏所有格子 / 桌面格子设置…。优先注册成所有用户都能看到的一项
  （需要管理员权限），没有权限就只注册给当前用户；应用升级或换目录后会自动指向新位置。
  Windows 11 的新版右键菜单只列系统命令，这一项在**「显示更多选项」**里（按 Shift+F10 直接就是那一版）。
- 这项现在排在「显示更多选项」的**最底下**（「个性化」后面），和桌面整理类工具追加的位置在一起；
  以前不指定位置时，它会夹在「粘贴」和一堆第三方项中间，每次都可能不一样。
- 新增**收纳盒**：不绑定任何文件夹的格子，背后由应用自己在「文档\HexBench 收纳」下建一个目录，
  什么文件都能往里拖。删除时可以选**移到桌面 / 保留文件 / 删到回收站**，不会悄悄把文件弄丢。
- 新增**整理盒**（收纳盒 + 规则）：按**后缀 / 名称包含 / 大小 / 修改时间**从来源目录里挑文件收进来，
  可以顺便收进盒子里的子目录。来源是桌面、下载或自己选的文件夹；一条规则都没有条件时
  会把来源里的所有文件都收进来，设置页会先提醒。
- 来源目录一有变化就自动整理（防抖 1.5 秒），开机后也会先整理一遍；也可以关掉自动、手动点
  **立即整理**，或者先**预览**会收哪些文件。一次整理算一步撤销，Ctrl+Z 能整批退回去。
  盒子自己和它的收纳目录永远不会被再扫一遍。
- 修复：展开的格子**表头下面多出一条浅色带**（8px，颜色和表头一样，看着像表头往下
