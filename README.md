# HexBench

Windows 11 桌面效率工具集。三个工具共用一套设置：鼠标推到屏幕边缘切换虚拟桌面、一个热键呼出文件面板、把常用文件夹钉在桌面上；面板里还带便签、内置网页和右键手势。

- 平台：Windows 10 1809+ / Windows 11（x64）
- 技术栈：Tauri 2 + React 19 + Rust
- 许可：MIT

[English](README.en.md) · [更新日志](docs/CHANGELOG.md)

---

## 功能

| 工具 | 作用 | 入口 |
| --- | --- | --- |
| 边缘桌面 | 鼠标推到屏幕最外侧边缘，切换到上一个 / 下一个虚拟桌面 | 边缘触发；`Ctrl+Alt+Shift+P` 暂停 |
| 快捷面板 | 搜索、浏览、移动文件，写便签，开内置网页 | 默认 `Alt+1` |
| 桌面格子 | 把常用文件夹和收纳目录放到桌面上 | 托盘菜单，或设置 → 桌面格子 |

此外还包括：内置网页窗口、右键手势、全局热键、WebDAV 配置同步、后台静默更新、开机自启、亮暗主题。

## 安装

从 [Releases](https://github.com/punwong/hexbench/releases/latest) 下载最新安装包。

- Windows 10 1809+ / Windows 11，x64
- 需要 WebView2 运行时（Windows 11 自带）
- 安装包用 minisign 签名供自动更新校验；可执行文件本身暂未做代码签名

安装后程序常驻托盘，不占任务栏。第一次启动会打开主界面并显示一次使用引导。

仓库里的 `winget/manifests` 是待提交的 winget 清单，目前尚未合并到 winget-pkgs，暂不支持 `winget install`。

## 使用

### 边缘桌面

把鼠标推到屏幕**最外侧**的左边缘或右边缘，进入触发带后停留约 0.12 秒，切换到上一个 / 下一个虚拟桌面。

- 触发带默认贴在屏幕底部，占所在屏高度的 10%；左右两侧同时生效
- 只认整个桌面最外侧的边缘，两块屏之间的接缝不会触发
- 每块屏按自己的高度计算触发带，横竖屏混排手感一致
- 插拔显示器、改分辨率、转屏或改缩放后自动重算，不需要重新标定
- 触发后光标自动向内推 24 px，避免一次推到底连续切换

设置 → 边缘桌面：

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| 贴哪条边 | 底部 | 任务栏设为自动隐藏时可改成「顶部」 |
| 左右两侧 | 两侧 | 也可以只留左边或右边 |
| 占屏高比例 | 10% | 3%–50% |
| 停留阈值 | 120 ms | 进入触发带后停留多久才切换 |
| 冷却 | 500 ms | 两次切换之间的最小间隔 |
| 轮询间隔 | 50 ms | 检测光标位置的频率 |
| 向内推 / 内推距离 | 开 / 24 px | 切换后把光标推回屏幕内 |
| 防误触 | 开 | 按住鼠标、光标在任务栏、锁屏时不触发 |
| 进程黑名单 | 空 | 前台是这些进程时不触发（不区分大小写） |

「在屏幕上预览」会把触发带画在屏幕上几秒，用来确认位置或排查误触，不会切换桌面。暂停热键默认 `Ctrl+Alt+Shift+P`，在「应用 → 热键」里修改。

### 快捷面板

按 `Alt+1` 呼出面板，默认出现在鼠标附近，占工作区的 60% × 60%。

**查找与打开**

- 顶部搜索框同时搜索当前分类的文件、固定文件夹和便签
- 双击打开文件或文件夹；单击选中
- `Esc` 关闭面板，搜索框外按 `Backspace` 返回上一层

**文件操作**

- 空白处拖动（或按住 `Alt` 拖动）框选，`Ctrl+A` 全选
- `Alt+滚轮` 缩放图标大小
- 拖文件到左侧分类或固定文件夹上直接移动；跨盘移动带进度条，重名时询问
- 把文件从面板拖到资源管理器或其它程序，等于拖出
- `Ctrl+C / Ctrl+X / Ctrl+V` 与资源管理器共用系统剪贴板
- 删除进回收站，`Ctrl+Z` 可以还原（包括从回收站找回）

**分类与文件夹**

- 「分类」来自一个根目录：根目录下的每个子文件夹就是一个分类
- 分类可以拖动排序，点眼睛图标隐藏
- 右键分类可以新建子文件夹、重命名
- 「固定文件夹」用于除此之外的常用目录，可增删、排序
- 空白处右键弹出资源管理器原生菜单（新建、粘贴、Git、VS Code、压缩工具等已安装的扩展都在）

**面板本身**

- 拖边缘改大小、拖顶栏移动；尺寸和位置会记住（可在设置里关掉）
- 面板跟随设置里的浅色 / 深色主题

设置 → 快捷面板分为四块：**分类**（根目录、面板尺寸、呼出位置）、**固定文件夹**、**内置网页**、**便签**。

### 桌面格子

桌面格子是贴在桌面上的文件夹小窗，不占任务栏。

- 设置 → 桌面格子 → 「添加文件夹格子」选择文件夹，或「新建收纳盒」建一个收集目录
- 把文件拖进格子即可移入该文件夹；从格子里拖出等于移动
- 每个格子的右上角「⋯」菜单：重命名、更换文件夹、在资源管理器中打开、按名称 / 修改时间 / 大小 / 类型排序、锁定位置、隐藏、删除
- 删除格子只移除窗口，**不会删除文件夹和文件**；删除前会确认
- 勾选「按 Win+D 时保持可见」后，显示桌面时格子仍然可见
- 「移动时吸附」打开后拖格子会显示参考线并自动对齐，按住 `Alt` 可临时暂停吸附；「吸附到 8px 网格」让不贴边的位置也对齐网格
- 格子内容超出时右侧有滚动条；空文件夹会显示「这里是空的」
- 托盘右键菜单里有「显示全部格子」，可以一次找回被隐藏的格子

### 便签

便签用来存经常要重复输入的短文本：邮箱、地址、客服回复、代码片段。

- 快捷面板左侧「便签」一栏；也可以设置 → 快捷面板 → 便签 里管理和清空
- 点卡片进入编辑：标题 + 正文，支持 Markdown，写下去就自动保存，`Ctrl+Z` 撤销
- 拖图片到空白处新建一条便签，拖到卡片上追加到那条
- **发送**：面板收起，焦点回到呼出前的窗口，正文逐字输入到那里；图片不会输入，可以用「复制图片」把图片作为文件放进剪贴板
- 「发送后自动回车」适合聊天框和搜索框，写邮件正文时不要开
- 卡片上的图钉把便签钉到桌面：始终置顶、不进任务栏，Markdown 和图片直接显示；双击正文就地编辑，双击标题栏收起为一条窄条，点右上角 × 收回

便签就是普通文件：一条一个 `.md`，图片放在同一目录的 `images/` 里用相对路径引用。默认目录是 `文档\HexBench 收藏`，可以在设置里换成同步盘里的目录，任何编辑器和同步工具都能直接用。

### 内置网页

设置 → 快捷面板 → 内置网页：

- 添加常用网址，自动识别站点名和图标
- 网页窗口贴在屏幕左侧或右侧，宽度 / 高度按工作区百分比单独设置（默认 24% / 85%）
- 默认不跟随面板，需要时勾选「跟着呼出面板走」
- 面板收起后网页保留若干秒（默认 90 秒），可以继续看
- 记住位置和大小；顶栏用站点图标切换和刷新

### 手势

在文件区按住右键横向滑动：

- 左滑：后退；右滑：前进（可在设置里互换）
- 默认横向滑动超过 80 px 才执行
- 打开「显示轨迹」后拖动时会画轨迹线并在光标旁显示方向

### 热键

设置 → 应用 → 热键：

| 动作 | 默认 |
| --- | --- |
| 呼出快捷面板 | `Alt+1` |
| 暂停 / 继续边缘切换 | `Ctrl+Alt+Shift+P` |

点「设置热键」按下新组合键即可修改，「清除」解除绑定；注册失败会提示换一个组合。

### 托盘与启动

- 左键托盘图标打开主界面，右键打开菜单（显示全部格子、暂停、退出等）
- 「通用 → 常规」里可以开启开机自启（只进托盘，不弹窗）
- 「通用 → 显示器」可以在插拔屏幕后手动刷新布局
- 缩略图缓存位于 `%LOCALAPPDATA%`，上限 200 MB、自动清理；「通用 → 存储」可以查看和清空

## 配置

所有设置只有一份事实源：`%APPDATA%\io.github.hexbench\config.json`。设置界面里的修改会立即写入；也可以直接编辑这个文件（保存后重启生效）。

| 区块 | 内容 |
| --- | --- |
| `enabled` | 总开关 |
| `trigger` | 触发带位置、比例、停留、冷却、轮询、光标内推 |
| `guard` | 防误触：鼠标键、任务栏、锁屏、进程黑名单 |
| `hotkeys` | 呼出面板、暂停 |
| `monitors` | 每块屏幕的启用开关（按 EDID 存，只在本机有效） |
| `launcher` | 根目录、固定文件夹、面板尺寸、内置网页、站点列表 |
| `notes` | 便签开关、目录、发送后回车、钉在桌面的便签 |
| `gestures` | 手势开关、方向、触发距离、轨迹 |
| `desktop` | 桌面格子开关、吸附、可见性、每个格子的位置和视图 |
| `sync` | WebDAV 地址、用户名 |
| `updates` | 更新检查与忽略版本 |
| `ui` | 主题、语言、引导状态 |

写入采用 `config.json.tmp` → 替换 → 保留 `config.json.bak`，读取失败时回退备份。WebDAV 密码单独保存在 `credentials.bin`，用 Windows DPAPI 加密，不进 `config.json`。

### 配置同步（WebDAV）

设置 → 通用 → 配置同步：

- 填写 WebDAV 地址、用户名、密码，「测试连接」确认可用后保存
- 「上传配置」把本机设置写到云端，「拉取配置」用云端设置覆盖本机；两边都会先确认
- 可选启动时自动拉取；下载前比较时间戳，不静默覆盖较新的本机配置
- 密码本机加密保存，不会上传；显示器坐标和每屏开关不参与同步，换机器不会错位
- 兼容坚果云、Nextcloud、ownCloud、群晖、InfiniCLOUD 等标准 WebDAV 服务

## 更新

- 启动 3 秒后检查一次，之后每 10 分钟检查一次；打开主界面时如果距上次检查超过 2 分钟也会补查
- 发现新版本后在后台下载，下载完成才在侧边栏显示「新版本 x.y.z」和「更新」按钮
- 点「更新」后静默安装并自动重启；不想装就点右侧 × 忽略这个版本
- 也可以随时在「关于 → 检查更新」手动检查

更新地址固定为 `https://github.com/punwong/hexbench/releases/latest/download/latest.json`，安装包用 minisign 校验。需要镜像时 fork 后修改 `updates.endpoint`。

## 常见问题

**推到边缘没有切换？** 检查「边缘桌面」页的状态：总开关是否打开、是否处于暂停、光标所在屏幕是否被单独关掉、前台进程是否在黑名单里。

**热键没反应？** 组合键可能被别的程序占用，到「应用 → 热键」重新设置，注册失败时界面会提示。

**配置在哪？怎么备份？** `%APPDATA%\io.github.hexbench\config.json`，需要连同 `credentials.bin` 一起备份；也可以用 WebDAV 同步。

**便签存在哪？** 默认 `文档\HexBench 收藏`，每条一个 `.md` 文件。

## 开发

需要 Rust 1.85+、Node 22+、pnpm 10+ 和 MSVC 工具链。

```powershell
pnpm install
pnpm tauri dev      # 开发模式，热更新
pnpm tauri build    # 发布构建；签名时设置 TAURI_SIGNING_PRIVATE_KEY
```

测试与检查：

```powershell
cargo test --workspace
cargo clippy --workspace --all-targets -- -D warnings
pnpm exec tsc --noEmit
```

代码结构：

| 目录 | 内容 |
| --- | --- |
| `src-tauri/` | Tauri 入口、窗口管理、命令、托盘、更新 |
| `crates/hexbench-core/` | 配置、几何计算、便签、系统接口 |
| `crates/hexbench-fence/` | 桌面格子的原生窗口（D3D11 + Direct2D） |
| `src/` | React 前端：设置窗口、快捷面板、便签、浮层 |
| `docs/` | 开发与测试文档、更新日志 |

2. 更新 `docs/CHANGELOG.md`
